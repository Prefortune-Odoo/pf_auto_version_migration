Odoo Automatic Version Upgrade / Migration

1.From your main Odoo dashboard, locate and click on the Odoo Migration app icon to open the application.

2.On the Migration Tickets page, click the Start Migration button located in the top menu bar to launch the migration wizard.

3.The wizard popup will appear. Verify your Current Odoo Version and the Target Version, then click the Next button.

4.The next screen will display your server details and a complete list of your installed Custom Modules. Review this information and click Next.

5.An alert will notify you that a manual migration is required due to the custom modules. Fill out the required basic information (like your Contact Person Name) in the form below, then click Create Ticket.

6.You will be redirected to the form view of your newly created Migration Ticket, which displays a comprehensive summary of all your submitted request details.

7.You can now find and track your newly generated ticket (e.g., ticket 00049) directly from the main Migration Tickets list view.
